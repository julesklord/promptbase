## Quick Start

1. **Clone and Install**
   ```bash
   git clone https://github.com/julesklord/promptbase.git
   cd promptbase
   npm install
   ```
2. **Execute Development Server**
   ```bash
   npm start
   ```
3. **Access**
   Navigate to `http://localhost:5500`.

- **Persistence**: Static JSON.
- **Testing**: Playwright.
