# Project Soul

## Vision
To create the definitive repository of technical LLM prompts that empower engineers to build faster, safer, and more autonomous systems.

## Principles
1. **Engineering Over Conversation:** Prompts should be treated as code—structured, versioned, and validated.
2. **Community Ownership:** A living library that evolves through the contributions and feedback of the developer community.
3. **Zero-Framework Purity:** Maintain a clean, vanilla web implementation for the dashboard to ensure long-term maintainability.
4. **Validation is Mandatory:** Every prompt and UI feature must be backed by a testing strategy (Playwright).
5. **Radical Clarity:** Documentation should be distributed, surgical, and always relevant.

## Values
- **Integrity:** Curating only high-quality, technically sound prompts.
- **Efficiency:** Reducing the time between "problem" and "working solution" through better prompting.
- **Empowerment:** Giving builders the "red pill" for LLM interaction.
- **Hygiene:** Maintaining a clean, standardized repository following the Jules Dev Standard.
